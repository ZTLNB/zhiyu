# 模型连接与资料隐私说明

模型设置包含 API 地址、模型名称和 API Key。API 地址应填写支持 chat/completions 的服务地址，例如以 /v1 结尾的基础地址。

保存模型设置后，点击测试连接。测试会发送一条短消息到配置的服务，检索问答会发送问题、相关资料片段和最近的对话。

如果希望资料完全不离开设备，可以使用本地模型服务，或保持原文摘录模式。连接外部模型前，应了解该服务的数据处理规则。

密钥仅由本地服务端保存，状态接口不会返回真实密钥。备份文件也不会包含模型密钥。

常见故障有：API 地址不正确、模型名称不存在、密钥失效、服务额度不足和网络超时。发生故障时界面会显示错误，不会把检索摘录伪装成模型回答。
